BUBios for the SOYO SY-019L1 386 board

A 1992 AMI BIOS that stopped at 504 MB, rebuilt to reach 128 GB with LBA. It adds automatic IDE detection, a full-screen POST display and a new setup program, all inside the original 64 KB EPROM. Confirmed on real hardware.
